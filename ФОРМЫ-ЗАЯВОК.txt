КУДА УХОДЯТ ЗАЯВКИ С САЙТА ZOOEMBRIO
====================================

Формы (контакты + корзина) отправляются через FormSubmit.co AJAX.
Письмо уходит на ОБА ящика из .env:

  PUBLIC_FORM_EMAIL=info@zooembrio.ru   ← основное
  PUBLIC_FORM_CC=bmvz-8@yandex.ru       ← копия

После отправки страница НЕ уходит на экран FormSubmit —
на сайте появляется плашка:
  «Спасибо! В ближайшее время наши менеджеры свяжутся с вами!»


ПЕРВАЯ АКТИВАЦИЯ (обязательно один раз)
---------------------------------------
1. Отправьте тестовую заявку с сайта (или с локалки).
2. Откройте почту info@zooembrio.ru (основной ящик).
3. Найдите письмо FormSubmit «Activate Form» и нажмите ссылку.
4. Повторите тест — письма должны прийти на оба ящика.


ПРОВЕРКА НА ЛОКАЛКЕ
-------------------
Да, можно. Локальный npm run dev реально шлёт заявки на почту
через FormSubmit (это внешний сервис, не «заглушка»).

  1. ЗАПУСТИТЬ-САЙТ.bat  →  http://127.0.0.1:4321/contact/
  2. Заполните форму и отправьте.
  3. Проверьте оба ящика (и папку «Спам»).

Важно: до активации FormSubmit письмо может не прийти —
сначала нажмите Activate Form в info@zooembrio.ru.


ПОСЛЕ ИЗМЕНЕНИЯ .env
--------------------
Пересоберите и задеплойте dist/:

  npm run build
