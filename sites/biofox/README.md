# BIOFOX — архивная копия сайта (Tilda)

Статическая копия лендинга **«СРЕДЫ BIOFOX»** по скриншотам из редактора Tilda.

## Что внутри

- Одностраничный лендинг: миссия, продукты, FAQ, преимущества, команда, наука, отзывы, форма образцов, контакты
- Стили и структура близки к оригиналу на Tilda (чёрный header, оранжевый акцент `#F2552C`)
- Исходные скриншоты сохранены в `assets/images/reference/`

## Как открыть

Самый простой способ — открыть `index.html` в браузере.

Либо локальный сервер из этой папки:

```bash
cd sites/biofox
python3 -m http.server 5177
```

Затем: http://localhost:5177/
