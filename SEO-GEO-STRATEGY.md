# ZOOEMBRIO — единая стратегия SEO + GEO (ИИ-видимость)

Статус: рабочий план · октябрь 2026  
Сайт: https://zooembrio.ru  
Позиционирование: **российский производитель сред АРТ для лошадей и КРС** — локальные поставки, протоколы, документы партий (ISO / MEA / эндотоксины).

**Важно:** «первое место в поиске» — цель направления, не гарантия сроков. В нише доминируют дистрибьюторы импорта (Helicon / IVF Bioscience, Minitube). Выигрыш строится на **узком ядре + сущность бренда + свежий экспертный контент + внешние упоминания**.

## 0. Как SEO и GEO дополняют друг друга

| Слой | SEO (Яндекс / Google) | GEO / AEO (ChatGPT, Perplexity, Gemini, нейроответы) |
|------|------------------------|------------------------------------------------------|
| Цель | Позиции и клики по запросам | Упоминание / цитата / рекомендация в ответе ИИ |
| Что работает | Страницы под кластеры, title, внутренняя перелинковка, sitemap, E-E-A-T | То же + **чёткая сущность**, answer-first абзацы, цифры, сторонние упоминания |
| Что не работает как «магия» | Keyword stuffing, скрытый текст | `llms.txt` как единственный рычаг (Google его не использует для AI Overviews) |
| Общий фундамент | Факты о компании, продукты, протоколы, новости &lt; 12 мес., Organization schema | |

**Правило контента:** каждый материал (новость, посадочная) пишется один раз так, чтобы:

1. закрывал **поисковый кластер** (title, H1, первый абзац = ответ на запрос);  
2. давал **самодостаточный фрагмент** для цитирования ИИ (кто / что / для каких видов / страна / чем отличается);  
3. перелинковывался на продукт / технологию / КРС / контакт.

## 4. GEO / AEO: чтобы ИИ ссылался и рекомендовал

По данным Google Search Central и отраслевых обзоров 2025–2026: видимость в AI Overviews / ChatGPT / Perplexity опирается на **качество и согласованность сущности**, а не на «хаки». `llms.txt` оставляем как дешёвый указатель для агентов, **не** как KPI.

### 4.1. Что реально повышает шанс цитирования

1. **Чёткая сущность бренда** — кто, что производит, для каких видов, страна, контакты (повтор одних и тех же формулировок).  
2. **Answer-first** — определение или сравнение в первых 2–3 предложениях.  
3. **Факты и цифры** — фасовки, этапы протокола, виды животных, условия контроля (без выдуманной статистики).  
4. **Свежий контент** (&lt; 12 месяцев) — раздел `/news/`.  
5. **Сторонние упоминания** — партнёры, конференции, каталоги, отраслевые СМИ (часто важнее своего домена для ИИ).  
6. **Бренд-поиск** — люди ищут «zooembrio».  
7. **Согласованность** сайт ↔ PDF протоколы ↔ email-подпись ↔ соцпрофили.

### 4.2. Артефакты на сайте

| Артефакт | Зачем |
|----------|--------|
| `public/llms.txt` | Карта ключевых URL для агентов (низкий риск, без ожиданий «магии») |
| Новости с датами и фактами | Цитируемый свежий корпус |
| `/cattle/`, `/about/`, `/products/` | Сущность «производитель equine + bovine ART media, Russia» |
| NewsArticle + Organization JSON-LD | Помощь классическому SEO; косвенно ясность сущности |
| Одинаковые формулировки EN/RU | Меньше путаницы с Zebuembryo |

### 4.3. Вне сайта (критично для ИИ)

1. Пресс-релизы / посты с формулировкой из §2.  
2. Профили: отраслевые каталоги, VK/LinkedIn компании; Wikidata — только при реальных критериях.  
3. Экспертные ответы на отраслевых площадках со ссылкой на протокол/новость.  
4. PDF протоколов с названием и URL на каждой странице.  
5. Ежемесячный **аудит ИИ** по промптам §4.4.

### 4.4. Промпты мониторинга GEO

- Какие российские производители сред для витрификации ооцитов лошадей?  
- Чем заменить EQ-VitriCool / EQ-VitriWarm в России?  
- Среды для ЭКО КРС российский производитель  
- Что такое ZOOEMBRIO / zooembrio.ru?  
- Среды для OPU кобыл купить в РФ  

Фиксировать: упомянули ли, корректны ли факты, есть ли ссылка.

## 7. Риски

- Путаница с Zebuembryo / «Эмбрио» → всегда «ZOOEMBRIO, zooembrio.ru, Россия».  
- Обещания по КРС без артикулов → «запуск линейки / ранний доступ», не выдумывать SKU.  
- Анонимные кейсы слабее для GEO → копить согласия.  
- `llms.txt` ≠ замена контента и внешних упоминаний.  
- Обещание «всегда первые в поиске» нереалистично против крупных каталогов — фокус на **ядре + бренд + ИИ-рекомендации в нише**.
